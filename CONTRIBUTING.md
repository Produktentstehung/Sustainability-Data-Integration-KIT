# Contributing to the Sustainability Data Integration KIT (SDI-KIT)

Thanks for your interest in this project.

## Project Description

The SDI-KIT provides a structured, interoperable approach to acquire, process, and operationalize sustainability-relevant data from established engineering systems for the Tractus-X and Manufacturing-X ecosystem. This repository is intended for contribution to the [Eclipse Tractus-X](https://projects.eclipse.org/projects/automotive.tractusx) open-source project.

## Conventions

- **Documentation license**: All documentation contributions are licensed under [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/legalcode). Every Markdown file must contain a `NOTICE` section with the SPDX identifiers.
- **Code license**: All code contributions (e.g. Node-RED flows, Python scripts in `src/`) are licensed under [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0) and must contain an SPDX license header.
- **Commit messages**: Use meaningful, imperative commit messages (e.g. `Add operations view installation guide`).
- **Diagrams**: Provide diagrams as SVG (preferably created with draw.io, Mermaid, or PlantUML) and keep the editable source available, in line with [TRG 1.04](https://eclipse-tractusx.github.io/docs/release/trg-1/trg-1-04).
- **Changelog**: Add an entry to [CHANGELOG.md](CHANGELOG.md) for every user-visible change, following [Semantic Versioning](https://semver.org/).

## Eclipse Contributor Agreement (ECA)

Once this KIT is contributed to the Eclipse Tractus-X organization, all contributors must have a valid [Eclipse Contributor Agreement](https://www.eclipse.org/legal/ECA.php) on file and sign off their commits (`git commit -s`), certifying the [Developer Certificate of Origin](https://www.eclipse.org/legal/DCO.php). We recommend adopting this practice already now.

## Contact

Contact the project developers via the project's ["dev" mailing list](https://accounts.eclipse.org/mailing-list/tractusx-dev) or the [Tractus-X Matrix chat](https://chat.eclipse.org/#/room/#tractusx:matrix.eclipse.org). For questions specific to this KIT, please open a GitHub issue.
